- [ ] Fields and formats are explicit
- [ ] Expected result is stated
- [ ] At least one real screenshot for visual workflows
- [ ] Troubleshooting covers the common failure
- [ ] Related guides are relevant
- [ ] No internal implementation details
- [ ] Links resolve
