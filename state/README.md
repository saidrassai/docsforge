# State

`install-manifest.json` records every file this toolkit installed into OpenCode
and Oh My Pi, including:

- host root;
- managed relative path;
- canonical source;
- SHA-256 hash;
- file kind (skill, agent, command).

`status` compares hashes and reports missing or drifted files. `sync` updates
managed files and backs up the previous version. `uninstall` removes only
manifest-managed files and restores the matching pre-install backup for the
same host root.

Do not edit this file by hand. If it is lost, reinstall with
`docs-toolkit.mjs install --host all --force`; existing unmanaged files are
backed up, not silently discarded.
